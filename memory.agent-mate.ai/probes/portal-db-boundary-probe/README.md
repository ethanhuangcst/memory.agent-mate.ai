## 踩坑（本轮两处，都是**探针自伤**，非产品问题）

1. **`$(case … esac)` 会被 `)` 提前闭合** —— `case` 的分支 `)` 会被 `$( )` 当成**命令替换的结束** ⇒ 语法错。修法：判据一律写成**函数**再 `$(fn && echo 0 || echo 1)`。
2. **双引号里的反引号仍是命令替换** —— 文案里的 `` `script.sh` `` 被 shell 当命令执行（输出里出现 `command not found`）。这是仓内**坑 7**（`#1` 探针 README 已录：「探针输出文案一律不带反引号」）⇒ 本轮**又犯**。修法：输出文案里的反引号一律去掉或用单引号包住。
3. **本机后端必须 `exec`** —— `( cd … && node … ) &` 的 `${PID}` 是**子 shell** 的 PID ⇒ `kill` 只杀子 shell，`node` 变孤儿进程继续占端口。修法：子 shell 里 `exec node …`，让 PID 就是 node 的 PID。
