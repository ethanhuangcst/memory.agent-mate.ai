## 接管接口（给 `#13` / `#14` / 在线链路探针 `#6`）

生产上线后补**两条**（缺一不可）：
1. 主机外 `nc -z -w3 <host> 9077`（或 `curl --max-time 3 http://<host>:9077/metrics`）**必须失败/超时**；
2. **同一命令对门户的公网入口必须成功** —— 证明**探测通路有效**；否则 ① 的「失败」可能只是网络原因（**假绿**，与 `P1` 同因）。

## 踩坑（本轮 4 处：3 处探针自伤 + 1 处由正向控制抓到）

1. **`docker run <image> <args>` 是替换 CMD，不是追加** —— `python:3-alpine` 的 CMD 是 `python3`，只传 `-m http.server …` 会让容器去 exec `-m` ⇒ 退出 **127**、**根本没起监听**。**最险的后果**：`P2`（不可达）会**通过**，但原因是「监听没起来」而不是「绑了回环」= **假绿** ⇒ 修法是给完整命令（`--entrypoint python3`）。**这就是正向控制存在的理由**。
2. **宿主探容器 bridge IP 在 Docker Desktop 上不成立**（172.x 不由宿主路由）⇒ 同网判据**必须**在 sibling 容器里做；否则「不可达」会因**错误的原因**成立（同一类假绿）。
3. **compose 的 `command:` 是 JSON 数组**（`["serve", "--host", "127.0.0.1", …]` 参数间是 `", "` 不是空格）⇒ 判据按「空格」写会**假红**（`S3` 抓到）。修法：先「拉平」（去引号/逗号/方括号）再匹配。
4. **同一键名出现在注释里 ≠ 已启用** —— `grep -rIc 'AI_MEMORY_REQUIRE_API_KEY'`（**含注释**）会把制品里「将来必须启用」的**旁证**算成违规 ⇒ 判据只数**生效行**（`S5` 同批补上这条自检）。
