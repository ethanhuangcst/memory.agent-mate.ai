## 踩坑（本轮 3 处，全是探针自伤）

1. **`sed` 默认 BRE ⇒ `#+` 是字面量**（我按 ERE 写了两处小节切分，范围恒空 ⇒ 假红）⇒ 改用 `awk`（ERE）。
2. **标题层级不要写死**：`mcp-design` §6.2 是 `###`、`web-test` 的 L3 段落编号形态又不同 ⇒ 首版两处假红。修法：`^#+` 宽松匹配 + 关键处改用**语义锚**（`L3` + 「上线验收」）。
3. **「命令替换里再套双引号」的老坑**（`${f "x")}` 式笔误 ⇒ 语法/`bad substitution`）：先算进变量再拼文案（同 `#17` 踩坑 1）。
