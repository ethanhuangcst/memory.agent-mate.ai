# ADR-011: 文档风格 —— 状态语义一律由文字承载，禁用 emoji / 图标作标记

## Status

Accepted

## Context

- 自有 spec 长期用 `✅ ❌ ⚠️ 🟠 🔴 🟡 ☐ ⛔ 🚧 🆕 ⭐ ★ ▼` 承担四类语义：**任务状态**（已完成 / 进行中 / 待决策 / 待提供 / 未开始）、**是否**（是 / 否）、**告警**（注意）、**级别**（阻断 / 高危 / warn / info）。
- 这套写法有三个具体代价：
  1. **检索不到**：`grep "已完成"` 命中不了 `✅已完成`；状态分布在图标与文字两种写法里，审计只能靠肉眼看。
  2. **diff 不显义**：图标是纯装饰字节，改动混在长行里，review 时看不出语义变化（「已完成 → 未开始」与改一个错别字在 diff 上同形）。
  3. **渲染依赖字体**：部分图标在非 emoji 字体 / 纯文本环境里退化为豆腐块或空格，语义直接丢失。
- 目标风格：**干净 · geeky · neat** —— 文档靠文字与结构表达，不靠装饰。
- 约束：`ai-memory-mcp/` 是 vendored 上游（自带 `.git`），任何全仓批处理**不得**改动它，否则上游升级时会变成 rebase 冲突源。

## Decision

1. **禁用 emoji / 装饰图标承担语义**：自有文档（`memory.agent-mate.ai/` 全部 spec + `.codebuddy/plans/`）一律用文字表达状态、是否、告警与级别。
2. **替换映射（写新文档照此执行）**：
   - 任务状态：`✅已完成 / 🚧进行中 / ⏸待决策 / ⛔待提供 / ☐未开始` → `已完成 / 进行中 / 待决策 / 待提供 / 未开始`
   - 是否：`✅` `❌` **单独成格** → `是` / `否`；后接文字已自解释（「无公网入口」「必须绕过」「不需要」）→ **直接删**
   - 告警：`⚠️ …` → `注意：…`
   - 级别：`🔴 阻断 / 🟠 高危 / 🟡 warn / 🔵 info` → `阻断 / 高危 / warn / info`（H / W 分组本身已表达层级）
   - 装饰：`⭐ ★ 🔁 ▼` 删除；`🆕` → `新增：`；架构图流向 `▼` → `↓`
   - 决议表状态：`🟡 **本设计定稿**` → `已定稿（可翻转）`；`✅` → `已定稿`
3. **范围边界**：批处理只覆盖自有资产目录；`ai-memory-mcp/` 不动。
4. **原文引用例外**：文档中以代码块引用的**程序输出 / 固定话术**（如 `adr/ADR-005`「提示话术」= `scripts/upstream-preflight.sh` 的 stdout）**不得只改文档** —— 要么与脚本同批改，要么在文档里显式登记为「例外 + 理由」。当前唯一例外即 `❌ 准入判定：不通过`（理由：该话术标注「固定，禁止改写语义」）。
5. **脚本 / CI / 配置模板不在本决议范围**：`upstream-preflight.sh`、`.github/scripts/render-preflight.py`、`deploy/config.toml.tmpl` 是代码与程序输出，不是文档，保持原样。

## Rationale

- 备选一：**保留图标并统一图例**（在文档头声明 ✅=已完成 等）—— 未采纳：图例只在文件头有效，长文档滚动后失效，且不解决 grep / diff 问题。
- 备选二：**只删颜色圆点，保留 ✅/❌/⚠️**（图标最通用）—— 未采纳：这三者恰好是承载状态语义的主力，删一半等于没解决；且保留会让「是否」类单元格继续依赖图标。
- 备选三：**改用 Markdown 原生标记**（`[x]` / `[ ]`）—— 未采纳：复选框在表格里语义是「勾选」而非「状态机」，且与任务清单混淆。
- 文字方案的成本只有一行多几个字节，收益是可检索、可 diff、字体无关。

## Consequences

- 本次落地：自有 spec + plans 共 **14 个文件、180 处**替换；`make doc-links` / `make secret-check` / `make preflight-test` 全绿。
- 后续收益：状态可被 `grep` 审计（例如 `grep -c "未开始" sprint_plan.md`），覆盖审计与进度统计不再依赖肉眼看图标。
- 遗留：**1 处显式例外**（ADR-005 脚本输出原文），见 Decision 4；若要消除，须同批改 `scripts/upstream-preflight.sh`（离线自测只断言退出码与关键字，改输出安全）。
- 防复发：本 ADR 即规则；风格清理类批处理的操作注意（边界 / 原文引用 / 次生排版瑕疵）记入 `knowledge/git-tooling/gotchas.md` 第 5 条。
