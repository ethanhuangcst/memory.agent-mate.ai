CAPACITY

Capacity

Session limits are ours. Memory and storage quotas come from upstream. Over-limit is refused, not queued.

Read only. Limits are set in the server config; change them there and restart. This page never writes.

Where to change
On the host: the compose file and its env for session limits, the config file for upstream quotas. Not in this portal.
Then restart
Restart the portal so the new session limits apply. Upstream quotas are read on the next session.
Tool tier
The tier is per client and set in Admin MCP config, not here.
