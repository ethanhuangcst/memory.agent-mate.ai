Setup

Three steps: get a token, configure the client, verify one call.

  1. 01

    Get a token

    An admin issues it. The plaintext shows once, so copy it at once.

    No token yet? Scan with WeChat, or me@ethanhuang.com

    Your token looks like this:

    memo_a1b2.....4o5p6
  2. 02

    Configure the client

    Paste the block below into your MCP client (mcp.json).

    In Cursor: Settings → MCP → Add new MCP server, then paste the URL below.

    MCP URL https://memory.agent-mate.ai/mcp

    mcp.json 
    {
  "mcpServers": {
    "ai-memory": {
      "type": "http",
      "url": "https://memory.agent-mate.ai/mcp",
      "headers": {
        "Authorization": "Bearer memo_…"
      }
    }
  }
}
  3. 03

    Verify one call

    Ask it to remember one thing, then ask it back in a new chat.

    A real chat: the summary is stored and the memory id comes back.

Tools

These eight tools are yours. Ask in plain words; the client picks the tool.

Tool Does Example
memory_storeSave a memory. Same title and category merge. Kept 7 days by default, can be permanent.“Remember: my meeting notes are always bullet points.”
memory_recallFind memories by meaning, ranked by relevance, importance and recent use. The way to search in Chinese.“What was that note format I mentioned last time?”
memory_searchFind by exact keywords. Every word must appear.Memories containing both “redis” and “port”.
memory_getRead one memory in full by its id.Open the one with id 8f2c….
memory_listList memories by category, age or source. Up to 200.“List everything I saved about writing style.”
memory_load_familyLoad the most recent entries of one category.Load the last 10 entries of “core”.
memory_smart_loadSay what you want in one line; it picks the category and loads it.“Pull up everything about project decisions.”
memory_capabilitiesShow the current tier and tool count. Always available.“Which tools can I use right now?”

The tier is fixed by the server. Changing your client config will not change it, and you must reconnect after a change.
