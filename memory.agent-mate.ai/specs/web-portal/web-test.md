# web-test — 门户测试策略 · 测试计划 · 测试用例（Spec）

> **定位**：门户（admin portal）相关测试的**测试策略 + 测试计划 + 测试用例**唯一 spec。与 [`web-stories.md`](./web-stories.md)（AC）、[`web-design.md`](./web-design.md)（设计）、[`../mcp/mcp-test.md`](../mcp/mcp-test.md)（MCP 侧测试）互链不重复。
> **状态**：v1.0（新建） · as_of 2026-09-20 · 当前门户**代码为零**，本 spec 先于实现落盘
> **原则**：脚本化可重复 · 断言优先于观察 · **不泄密**（日志与断言中不出现令牌明文 / 记忆正文）· 隔离断言用**负向**用例（S4）

---

## §0 测试策略（L0–L3 分层）

| 层 | 名称 | 手段 | 防的失败模式 |
|---|---|---|---|
| **L0** | 组件/单元 | 门户自身逻辑：`handle` 白名单校验、模板占位符替换与断言、令牌哈希与常时比较、审计落库 | 输入校验与密钥处理错误（T2/T3） |
| **L1** | 集成（本地） | 门户容器 + 共享卷 `ai_memory_data`，建用户 → 签发 key → 经 `/mcp` 建会话 → 写入 → 断开 | 会话生命周期、子进程回收、库路径解析（S4） |
| **L2** | 端到端（真实客户端） | Cursor/Claude 以 `Authorization: Bearer memo_…` 指向 `<MCP_HOST>/mcp`，完成 initialize → tools/list → 实调用 | 真实客户端的传输/重连差异、CF 面隔离误配 |
| **L3** | 上线门禁（生产） | 面隔离、吊销即时生效、无 docker socket、UID/GID 对齐、备份边界 | 上线前的**阻断级**条件（含隔离负向验收） |

> **门槛**：L3 全绿才允许对外提供服务；其中 **负向用例（S4 / 路径穿越 / 面隔离）不过 = 阻断**。

## §2 测试用例

### L0 组件

| ID | 用例 | 断言 |
|---|---|---|
| TC-P-L0-01 | `handle` 校验 | 匹配 `^[a-z0-9_-]{1,32}$` 通过；`../`、`/`、超长、大写、空值均**拒绝** |
| TC-P-L0-02 | 模板替换与断言（正常） | 替换后 `AI_MEMORY_DB=/data/users/<handle>/ai-memory.db`，且 `AI_MEMORY_AGENT_ID=human:<handle>` |
| TC-P-L0-03 | 模板替换与断言（**负向**） | `AI_MEMORY_DB` 置空 / 不含 handle / 不以 `/data/users/` 开头 → **拒绝启动会话**并告警（S4） |
| TC-P-L0-04 | 令牌存储与比较 | 库内只存 `sha256` + `key_prefix`；**无明文**字段；比较为常时比较 |
| TC-P-L0-05 | 审计字段 | 会话审计行**含解析出的库路径**；审计/日志中**无**令牌明文 |
| TC-P-L0-06 | 启动自检 — 用户目录可写 | `/data/users` 不可写（缺 setgid 引导）→ **拒绝启动**并明确报错；可写 → 自检通过 |
| TC-P-L0-07 | 启动自检 — 向量服务可用性 | 门户专用凭据缺失或返回维度 ≠ `1024` → **拒绝启动**；不得以「检索静默降级」继续提供服务 |
| TC-P-L0-08 | 启动自检 — 版本断言 | 镜像内二进制版本 ≠ [`../../upstream.lock`](../../upstream.lock) → **拒绝启动**并指出版本漂移 |
| TC-P-L0-09 | 启动自检 — 关键校验在位 | `handle` 白名单 / 启动模板断言缺失 → **拒绝启动** |

### L1 集成（本地，门户 + 共享卷）

| ID | 用例 | 断言 |
|---|---|---|
| TC-P-L1-01 | 建用户 → 目录创建 | `/data/users/<handle>/` 存在，mode `0700`，属主 `aimem` |
| TC-P-L1-02 | 签发 key | 明文仅在创建响应出现一次；再次列出**不可取回**明文；目录幂等确保存在 |
| TC-P-L1-03 | 经 `/mcp` 建会话并写入 | `initialize` → `tools/list` → `memory_store` 成功；库文件落在 `/data/users/<handle>/ai-memory.db` |
| TC-P-L1-04 | 会话结束回收 | 客户端断开后 `ps` 中该 ai-memory 子进程**已消失**（无僵尸、无泄漏） |
| TC-P-L1-05 | 子进程不跨用户复用 | 两个不同 handle 的会话对应**两个**进程；不存在会话池复用 |
| TC-P-L1-06 | 多 key 同库 | 同一用户两把 key → 解析到同一 handle / 同一库，记忆互见 |
| TC-P-L1-07 | 跨用户隔离（正向） | A 写入后 B 检索**未命中**；B `memory_get <A id>` → 不可见 |
| TC-P-L1-08 | 无 docker socket | 门户容器内**不存在** `/var/run/docker.sock`（β′ 验证） |
| TC-P-L1-09 | UID/GID 对齐 | 门户镜像内 `aimem` 的 UID/GID **等于**上游镜像内 `aimem`（否则 SSH 路径写不进去） |
| TC-P-L1-10 | 门户库边界 | 门户库**不在** `/data` 下 |
| TC-P-L1-11 | 制品契约核对 | 二进制路径 `/usr/local/bin/ai-memory`；底座 bookworm 系 + `ca-certificates`；容器用户 `aimem` —— 三项探针核对通过；缺任一项或改名即**失败**（负向） |
| TC-P-L1-12 | 版本注入与不继承上游默认值 | 镜像 tag 来自 [`../../upstream.lock`](../../upstream.lock)（构建参数）而非手写；门户**不继承**上游 `ENTRYPOINT` / `CMD` / `ENV` |
| TC-P-L1-13 | 门户运行身份与容器加固 | 以非 root `aimem` 运行；根文件系统除必要挂载外**只读**；容器有资源限额 |

### L2 端到端（真实客户端）

| ID | 用例 | 断言 |
|---|---|---|
| TC-P-L2-01 | 客户端带令牌接入 `<MCP_HOST>/mcp` | 完成 initialize + tools/list + 一次实调用成功 |
| TC-P-L2-02 | 无令牌 / 已吊销令牌 | **拒绝**建立会话（不降级匿名） |
| TC-P-L2-03 | MCP 面不被 CF Access 拦截 | 客户端**未**收到 302/HTML（否则表现为「连不上」） |
| TC-P-L2-04 | 接入说明页可达性 | 新用户按页面指引 ≤ 3 步完成接入并成功调用一次 |
| TC-P-L2-05 | i18n | 中/英切换生效；新增语言不改业务逻辑 |

### L3 上线门禁（生产，阻断级）

| ID | 用例 | 断言 |
|---|---|---|
| TC-P-L3-01 | **S4 负向**（准入门槛） | 人为置空模板 `AI_MEMORY_DB` → 门户**拒绝**会话并告警，**不得**静默落 `/data/ai-memory.db` |
| TC-P-L3-02 | 路径穿越负向 | `{handle}` 替换为 `../` 等非法值 → 拒绝；`/data/users/` 下不出现预期外目录 |
| TC-P-L3-03 | **面隔离** | 在 `<MCP_HOST>` 请求管理 API → 拒绝；在 `<ADMIN_HOST>` 请求 `/mcp` → 拒绝 |
| TC-P-L3-04 | 吊销即时生效 | 吊销后新建会话被拒、**既有会话被终止**（子进程被 kill） |
| TC-P-L3-05 | 隔离交叉验证（生产卷） | 跨用户检索未命中 + `memory_get` 不可见 + 主库计数不变 |
| TC-P-L3-06 | 并发与限流 | 超每 key / 全局并发上限时**明确拒绝**（而非排队致死）；空闲超时与单会话时长生效 |
| TC-P-L3-07 | 配额生效 | 改上游 `[limits]` 后超限写入**被拒**；`max_inflight_requests` 对 stdio 是否生效**已实测并登记结论** |
| TC-P-L3-08 | 备份边界 | 备份脚本遍历用户库时**不含**门户库；门户库单独备份；含 sha256 校验 |
| TC-P-L3-09 | 无残留 | 会话开始前后 `/data/users/` 下**不出现**其他用户的库或临时文件 |

## §3 验收清单（上线前逐项打勾）

**继承** [`../mcp/mcp-design.md`](../mcp/mcp-design.md) §6.3（每库独立计数 / 跨用户未命中 / `memory_get` 不可见 / 库属主 `aimem` / 维护覆盖 / 备份覆盖 / 吊销即时），**并新增门户侧**：

- [ ] 用户 A 的 `memo_` 经 `<MCP_HOST>/mcp` 建会话后，实调用写入落在 `/data/users/a/ai-memory.db`，**且**审计行记录该路径
- [ ] 会话开始前后 `/data/users/` 下**没有**出现其他用户的库或临时文件
- [ ] 会话结束（客户端断开）后 `ps` 中该子进程**已消失**
- [ ] **S4 断言有效**（置空 `AI_MEMORY_DB` → 拒绝并告警，不静默落主库）
- [ ] `{handle}` 替换为 `../` 等非法值 → 拒绝（路径穿越无效）
- [ ] 面隔离双向拒绝（MCP 域名命中管理路由 / 管理域名命中 `/mcp`）
- [ ] 门户容器**不**包含 `/var/run/docker.sock`
- [ ] 门户镜像内 `aimem` 的 UID/GID **等于**上游镜像内 `aimem`
- [ ] 吊销 key 后：新建会话被拒、既有会话被终止
- [ ] 门户自己的库**不在** `/data` 下；备份脚本遍历用户库时**不含**门户库
